# NCLEX Amplified Interns — Landing Page

The official internship and OJT landing page for **NCLEX Amplified Review Center**.

## 🌟 Highlights
- **Scroll-Driven 3D App Dashboard Mockup**: Perspective resizing animation transitioning from prominent 3D hero display to flat centered layout.
- **Dedicated 500-Hour IT/CS Curriculum**: 5-phase interactive roadmap covering Frontend, Backend, DevOps/LAN, and Capstone.
- **Interactive Multi-Step Application Modal**: Program validation (BSIT / BSCS), department routing, and live success state.
- **Intern Testimonial Carousel**: Multi-slide student feedback showcase with auto-rotation, arrow controls, navigation dots, and touch swipe gestures.
- **FAQ Accordion & Department Drawers**: Smooth, accessible accordion and drawer modals.

## 🚀 Running Locally
```bash
# Clone the repository
git clone https://github.com/ciceronkeith4-code/Intern-Landing-Page.git

# Navigate to project directory
cd Intern-Landing-Page

# Start local server
node server.js
```
Open `http://localhost:3000` in your browser.
